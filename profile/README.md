# FOURIER Doctoral Network

**FOURIER** is a Marie Skłodowska-Curie Actions Doctoral Network for digital inspection and smart infrastructure management. Its doctoral candidates develop new AI approaches for inspection procedures, structural health monitoring (SHM) data processing and resilience decision-making.

🌐 Project website: [fourier-msca.eu](https://fourier-msca.eu/)

This GitHub organization collects the open research outputs of FOURIER doctoral candidates: code, models, data descriptions and supporting material for publications.
